# Contribution guidelines

Run the tests and lint checks before proposing changes. Explain changes to grain, monetary definitions or incremental behavior. Preserve publication atomicity and quality-gate semantics. Generate fresh benchmark results in a new directory and retain the original raw measurements. Use synthetic test data and supply attribution for external material.

Cloud operations, repository publication and license selection require owner approval. Preserve real contribution history. If the Git client offers automatic AI co-author trailers, use the owner’s requested setting for future CloudLake commits. The workspace currently has no repository configuration.
